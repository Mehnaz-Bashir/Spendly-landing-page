# Spendly

A modern, responsive personal finance landing page built with React and Vite.

## Live Demo

👉 https://spendly-landing-page-one.vercel.app/#final-cta

## GitHub Repository

https://github.com/Mehnaz-Bashir/Spendly-landing-page

## Features

- Responsive design for desktop and mobile
- Hero section with clear call-to-action
- Product dashboard preview
- Features section
- How It Works section
- Spending Insights section
- Smooth anchor navigation
- Hover micro-interactions
- Final call-to-action section

## Tech Stack

- React
- Vite
- JavaScript
- HTML
- CSS
